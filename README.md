# 📈 Trading Simulator

Learn how to trade stocks with $10,000 in virtual money. No real money, no real risk - just learning!

## Features

✅ **Buy & Sell Stocks** - Trade real stocks using live market data  
✅ **Portfolio Tracking** - Monitor your holdings and performance  
✅ **Real Price Data** - Live stock prices via Alpha Vantage API  
✅ **Performance Analytics** - Track your profit/loss and return percentage  
✅ **Transaction History** - See all your trades  
✅ **Simple & Clean UI** - Intuitive interface for beginners  

## How to Run Locally

### Prerequisites
- Python 3.8+
- pip (Python package manager)

### Setup

1. **Clone the repository**
```bash
git clone https://github.com/limdameli7-prog/trading-simulator.git
cd trading-simulator
```

2. **Install dependencies**
```bash
pip install -r requirements.txt
```

3. **Run the app**
```bash
python app.py
```

4. **Open in browser**
```
http://localhost:5000
```

That's it! Start trading 🚀

## How to Deploy (Free)

### Option 1: Heroku (Recommended)

1. **Create a Heroku account** at https://www.heroku.com
2. **Install Heroku CLI** from https://devcenter.heroku.com/articles/heroku-cli
3. **Deploy in 3 commands:**
```bash
heroku login
heroku create your-app-name
git push heroku main
```

Your app will be live at `https://your-app-name.herokuapp.com`

### Option 2: Railway.app

1. Go to https://railway.app
2. Click "New Project" → "Deploy from GitHub"
3. Select this repository
4. It deploys automatically!

### Option 3: Render.com

1. Go to https://render.com
2. New → Web Service
3. Connect GitHub repo
4. Deploy!

## How to Use

1. **Enter a stock symbol** (e.g., AAPL, GOOGL, MSFT)
2. **Enter quantity** (number of shares)
3. **Click "Buy Stock"** to purchase
4. **Watch your portfolio** update with real prices
5. **Sell when ready** to lock in profits or cut losses

## Learning Tips

💡 **Diversify** - Don't put all money in one stock  
💡 **Research** - Look up companies before buying  
💡 **Long-term thinking** - Don't panic sell on bad days  
💡 **Track patterns** - Notice market trends  
💡 **Start small** - Buy fewer shares to learn
